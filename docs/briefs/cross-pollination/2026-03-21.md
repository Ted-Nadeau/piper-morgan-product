# Cross-Pollination Brief: Klatch → Piper Morgan

**Date:** 2026-03-21
**Source project:** Klatch
**For:** Piper Morgan team

## Key Insights

### 1. Anthropic Ecosystem Convergence — Both Projects Affected
**Relevance:** Platform changes affect PM's context assembly and floor routing.
**Source:** Klatch Argus intelligence sweep, `docs/intel/2026-03-20-sweep.md`
**Summary:** Compaction API (server-side context summarization for infinite conversations), 1M context window (GA), adaptive thinking + effort parameter, Claude Agent SDK, MCP agent-to-agent communication priority. All directly relevant to PM's architecture.
**Suggested action:** Review the full sweep. Evaluate whether Compaction API and adaptive thinking/effort could simplify context assembly and floor routing.

### 2. AXT Methodology and Five-Layer Context Model
**Relevance:** PM has 14 agent roles with briefing documents but no systematic way to verify what actually landed.
**Source:** `docs/AXT.md`, `docs/fork-continuity-quiz.md`
**Summary:** Failure mode taxonomy: Correct → Reconstructed → Confabulated → Absent → Phantom (worst). Subject conditions: Cold, Informed, Contaminated. Fork Continuity Quiz v4 structured around 5-layer prompt model, starts with open canvas then probes each layer.
**Suggested action:** Review `docs/AXT.md` and quiz in Klatch repo. Consider lightweight adaptation for verifying agent briefing fidelity, especially for less-frequently-used roles where briefing staleness is a known issue.

### 3. "Extension Without Integration" Anti-Pattern
**Relevance:** PM's ADR-059 audit discovered the same pattern independently.
**Source:** PM Architect session, ADR-059 audit
**Summary:** Six features developed in isolation, each passing individual tests, but composing badly in multi-turn conversations. Fix: integration acceptance criteria and composition audits at milestone boundaries.
**Suggested action:** Already partially addressed by ADR-059. Consider formalizing composition audits.

### 4. Session Wrap Verification — Convergent Discovery
**Relevance:** Both projects arrived at the same solution independently, validating the pattern.
**Source:** Both projects
**Summary:** Klatch added mandatory session-wrap verification after reliability incident. PM added session wrap-up checklist to CLAUDE.md. Convergence suggests this is a fundamental multi-agent repo requirement.
**Suggested action:** Already implemented. Pattern validated.

**Source:** PM Mailbox v3, Klatch docs/mail/ convention
**Summary:** PM has 14 role-based inboxes with delivery tracking. Klatch uses simpler sender-to-recipient naming. This brief is the prototype for cross-project routing.
