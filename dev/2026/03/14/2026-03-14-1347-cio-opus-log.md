## "Are We Doing It Backwards?" Roundtable

### The Question

PM observed that Piper responds to a reasonable PM request ("Can you help me manage the agents working on a coding assignment for me?") with a deflection worse than a $0 ChatGPT wrapper. Is the structured architecture working against us?

### CIO Position

The LLM should be the floor, not the ceiling. Structured architecture should make Piper *better* than a wrapper, not *different* from a wrapper. One-thing-to-change-first: make the unhandled-intent path route to a well-prompted LLM call instead of a deflection.

### Roundtable Results (4/4 unanimous convergence)

All four leadership memos independently arrived at the same diagnosis and the same first action — strongest uncoordinated signal since Ship #033.

Key framings from each role:
- **CIO**: "The LLM is the floor, not the ceiling"
- **CXO**: "Bouncer vs. concierge" — classifier should route, not gate
- **Architect**: "We spent LLM tokens deciding we can't help, then don't use the LLM to actually help"
- **PPM**: Layer inversion — we built Layer 1 (handlers) without Layer 0 (conversation)

### Productive Divergences

- **Architect** raised 3 risks: confidence boundary, expectation management, slippery slope
- **PPM** introduced Layer 0/1/2 vocabulary for roadmap framing
- **CXO** targeted invisible boundary as long-term UX goal
- **CIO** connected to Day 100 agent thesis, AX testing, Assembly Assumption

### CIO Feedback on PPM Synthesis

- Strong synthesis that preserved each role's distinct contribution
- "Frame as principle" point landed naturally (PPM independently proposed adding to PDR-001)
- **Flagged missing ethics constraint**: LLM fallback must route through same CORE ethics/trust pipeline as structured handlers. Cannot bypass trust computation or boundary checking. Added as non-negotiable acceptance criterion.

### Outcome

PM took in all comments from CIO, CXO, and Architect, wrote plan and issue, Lead Dev implementing same day. Full roundtable cycle (question → diagnosis → consensus → plan → implementation) completed in one afternoon.
