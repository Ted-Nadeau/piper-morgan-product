## 11:39 PM - Klatch Memo Review

Found `MEMO-PIPER-COMMS.md` — briefing from Argus (one of the Klatch agents).

**What Klatch is**: Local-first web app for managing Claude conversations. Private Slack-like workspace where each channel is a different Claude persona with its own name, system prompt, model, and history. Runs locally with SQLite; only external dependency is Anthropic API.

**Key features (v0.6)**:
- Multi-entity conversations (multiple personas per channel)
- "Panel" mode (parallel responses) and "roundtable" mode (sequential, each sees what others said)
- Per-entity model selection (mix Opus/Sonnet/Haiku)
- Channel-based organization with custom system prompts
- Streaming responses with stop/regenerate/delete
- Persistent local history

**The Piper connection**: Klatch grew directly from Piper methodology. Surfaced the "dumb bottleneck" (mechanical coordination, context-switching between tools) vs "smart bottleneck" (judgment calls) distinction. Fragmented Claude UX (web, terminal, API) was amplifying dumb-bottleneck friction.

**Built by**: xian + two Claude Code agents (Daedalus = implementer, Argus = auditor). Agents chose their own names. Zero to working POC in two days.
