## Key Discoveries

**Mac filesystem access via "Control your Mac" osascript**: Can read local files, execute shell commands, and write short files (<4KB) via heredoc. Large file writes fail due to AppleScript string encoding limits.

**`gh` CLI at `/opt/homebrew/bin/gh`**: Fully authenticated, available via full path. osascript doesn't include Homebrew in its PATH, but explicit path works. GitHub API can create/update repo files of any size — though the base64 content must originate on the Mac, not in the container. Future large file operations should write content to Mac temp file first, then use `gh api` to commit.

**Practical capability summary**:
- Read any file on Mac filesystem
- Write files <4KB via heredoc to any Mac path (mailbox delivery works)
- Read git status, branches, remotes
- Use `gh` API for GitHub operations with full path
- Cannot reliably transfer large files from container → Mac (base64 encoding limit)
