## Innovation Backlog Review

PM shared three collected items for CIO analysis:

### 1. "Death of the AI Wrapper" (Collins/Medium, Feb 19)
Riffing on Amodei/Patil Anthropic Builder Summit advice. "Skate to the puck" = our Time Lord philosophy. "Build for Day 100" = our infrastructure-first approach. Key validation: Piper isn't a thin wrapper because its value is in the domain model, entity relationships, and accumulated user context — not the LLM layer. "World of Atoms" argument maps imperfectly (our moat is methodology depth, not regulatory barriers), but structural logic is the same.

### 2. Knowledge Graph Extraction Challenges (Yáñez Romero/Medium, Jan 15)
LLMs produce fragmented KGs because they treat extraction as generation rather than classification. Coreference problem ("Party A" vs "the aforementioned party" = separate nodes) maps directly to Piper's future entity extraction from conversations. Asserted vs. augmented graph distinction maps to our trust/provenance architecture. Pipeline error propagation (90% × 90% = 81%) relevant to multi-stage learning pipeline design. **Action**: Add to CITATIONS.md, flag for Architect when learning system reaches entity extraction stage.

### 3. Jesse Vincent's Engineering Notebook (Prime Radiant, Feb 23)
Most directly actionable. Automated ingestion of Claude Code JSONL → LLM summarization → browsable journal/project/calendar views. **Convergent evolution** with our omnibus system — same underlying problem (agentic work generates too much output for humans to track), arrived at independently from different angles (his: solo developer tracking code; ours: PM orchestrator tracking multi-agent strategic work).

**Where we're ahead**: Cross-agent coordination, strategic decisions, methodology evolution, leadership analysis layer.
**Where he's ahead**: Automated and open-source. Our system requires manual Docs agent synthesis sessions.

### Cross-Cutting Theme
All three pieces point to the same insight: **the synthesis layer is becoming a first-class infrastructure concern.** The value isn't in the LLM call, it's in what you do with accumulated context over time. That's Piper's core thesis.
