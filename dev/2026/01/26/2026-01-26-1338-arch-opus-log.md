**MVP vs. V2 Rubric** (from PPM):

| Question | MVP (do now) | V2 (defer) |

**What MUX-V2 Represents**:
- Multi-entity conversations (PDR-101)
- Advanced reference resolution
- Multi-view projections
- Slack threading with full context
- Cross-session memory beyond 24-hour window

**What MVP Represents**:
- Core features functional
- Trust-appropriate proactivity
- Consciousness present
- **Active processes don't derail** ← This is why ADR-049 is MVP
- Basic context continuity
