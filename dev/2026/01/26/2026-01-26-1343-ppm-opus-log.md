## PM Discussion: Phasing Philosophy (1:53 PM)

PM asked for clarity on what "MUX-V2" represents and the rubric for deferring work.

### Key Insight

"V2" is misleading—implies version bump or rewrite. Better framing:

**Foundation** (now) → **Advanced Layer** (later)

Same models, same schema, increasing implementation depth.

### The Rubric

| MVP (Foundation) | Advanced Layer |
|------------------|----------------|
| User notices gap = fix now | Graceful degradation OK |
| Schema/models in place | Full implementation depth |
| Single-user coherent | Multi-party operational |
| Core loop works | Sophistication enhancements |

### Applied

| Item | Layer | Why |
|------|-------|-----|
| ADR-049 (derailment) | Foundation | User notices, feels broken |
| ADR-050 Phase 0 | Foundation | Schema work, done |
| ADR-050 Phases 1-3 | Advanced | Single-user doesn't need yet |
| Multi-chat | Advanced | Multi-party scenario |
