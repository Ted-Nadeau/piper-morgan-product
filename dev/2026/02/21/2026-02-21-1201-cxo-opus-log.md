### Five Foundational Principles
1. Conversation as Collaboration (not interface)
2. Implicit Over Explicit (confirmation)
3. Information Flows Forward (never re-ask)
4. Graceful Over Rigid (handle unexpected)
5. Trust Governs Autonomy (proactivity earns trust)

### Anti-Flattening Table
| Vision | Flattened Version |
|--------|-------------------|
| Natural workflow invocation | Explicit command required |
| Implicit confirmation | Confirm dialog for everything |
| Multi-intent handling | "One thing at a time please" |
| Contextual proactivity | Random suggestions |
| Graceful topic shifts | "Complete current workflow first" |

### B2 Dimensions
1. Flow (context continuity)
2. Discovery (capability finding)
3. Proactivity Balance (helpful not annoying)
4. Recovery (graceful failure)
5. Voice Consistency (same "person")
